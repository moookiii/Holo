# ASTRA WORKING BEHAVIOR

# DEFINITION OF PREMIUM

"Premium" means:

precision;
restraint;
depth;
sharpness;
responsiveness;
controlled highlights;
strong materials;
excellent motion;
no obvious shortcuts;
no visual noise without purpose.

It does NOT simply mean:

more bloom;
more glow;
more saturation;
more effects;
more UI;
more particles.
